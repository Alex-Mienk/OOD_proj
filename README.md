## Controls

### Movement
| Key | Action |
|----|-------|
| W | Move up |
| A | Move left |
| S | Move down |
| D | Move right |

### Interaction
| Key | Action |
|----|-------|
| E | Pick up item from the current tile |
| R | Drop the last item from inventory |
| Z | Drop the item held in the left hand |
| X | Drop the item held in the right hand |

### Game
| Key | Action |
|----|-------|
| Q | Quit the game |

### Notes
- Items can be picked up only if the player stands on the same tile as the item.
- Weapons are equipped automatically when picked up.
- If both hands are full, a weapon cannot be picked up and will remain on the ground.
- Two-handed weapons (e.g., `DoubleSword`) occupy both hands.
- Dropping a two-handed weapon will free both hands.
